# Simulações de física

Atividade da faculdade de mar/2022 a dez/2023. Publiquei anos depois (nov/2026) e não atualizei nada.

Projeto onde fui juntando simulações de física entre 2022 e 2023. Algumas calculam o movimento direto pelas fórmulas, como o `MRUV.cs`, e outras usam o Rigidbody do Unity. Tem MRU e MRUV, lançamentos, leis de Newton, impulso, colisões, MHS, figuras de Lissajous, empuxo, centro de massa e uma sinuca.

O histórico tem três versões: o pacote de 10/11/2023, o de 17/11/2023 e a versão final de dezembro.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2021.3.18f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
